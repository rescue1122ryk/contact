📤 Day Off Check — Upload Monthly Data

Choose one or more monthly Day Off Check files (CSV or Excel): Name, Employee Number, Station Name, then one column per date in that month with each day's code (M, e, n, admin, OFF, On Leave, etc). Cells marked OFF are counted as that employee's day off for the month. The rows get added to the end of the existing Day Off Check records — nothing already saved is removed.

⚠ Duplicate Contacts

Contacts that share the same Employee Code, or the exact same First + Last name, are grouped below. Review each group and delete whichever entry is the redundant copy — nothing is removed automatically.

🕐 Backups

A backup is saved automatically every time data is synced to the linked Excel file — the last 10 are kept. Restoring replaces current Contacts, Duty/Leave events, and Leave data with the selected version (the current state is backed up first, so you can undo a restore too).
